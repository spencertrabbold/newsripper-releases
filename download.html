News.Ripper 3.9.5

Filename workflow and Rumble support update for newsroom use.

Download NewsRipper 3.9.5 Installer

What changed

  • Added an editable filename field, smarter automatic filename suggestions, and collision-safe naming.
  • Improved Facebook filename cleanup by removing leading engagement counts such as reactions, shares, and comments.
  • Improved Rumble automatic naming while retaining custom filename support.
  • Rumble downloads can select the highest available safe HLS rendition and produce Premiere-friendly H.264/AAC MP4 files.
  • Existing URL safety, filename hardening, magic-byte validation, Zone.Identifier, cancellation, cleanup, and finalization protections remain enabled.
  • The release build process was hardened for more reproducible packaging, and the splash screen now matches version 3.9.5.
Note: This page is for limited newsroom testing. Code signing is pending.
